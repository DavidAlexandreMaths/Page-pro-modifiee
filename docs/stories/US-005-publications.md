# US-005 — Section Publications

**Statut :** ✅ Terminé
**Priorité :** 🟡 Moyenne

## Description

En tant que visiteur académique, je veux consulter la liste des publications et présentations du doctorant afin d'évaluer ses contributions scientifiques.

## Critères d'acceptation

- [x] Liste stylisée de publications
- [x] Année, titre, auteurs, revue visibles
- [x] Liens vers arXiv/HAL
- [x] Section présentations en conférence
- [x] Design cohérent avec le reste du site

## Notes techniques

- Cards de publication avec hover effect
- Liens externes ouverts dans un nouvel onglet (`target="_blank"`)
