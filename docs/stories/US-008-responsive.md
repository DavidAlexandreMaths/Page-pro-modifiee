# US-008 — Responsive Design

**Statut :** ✅ Terminé
**Priorité :** 🔴 Haute

## Description

En tant que visiteur mobile/tablette, je veux que le site s'adapte parfaitement à mon écran afin d'avoir une expérience de lecture optimale.

## Critères d'acceptation

- [x] Layout adaptatif (desktop, tablette, mobile)
- [x] Menu hamburger en mobile
- [x] Cards empilées verticalement en mobile
- [x] Tailles de texte adaptatives (clamp)
- [x] Canvas hero toujours plein écran
- [x] Pas de scroll horizontal

## Notes techniques

- Breakpoints : 768px (mobile), 1024px (tablette)
- Utilisation de `clamp()` pour les tailles fluides
- CSS Grid et Flexbox pour les layouts adaptatifs
